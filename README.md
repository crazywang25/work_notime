# 개인 NEXTEP

로그인한 NEXTEP에서 즐겨찾기를 누르면 새 탭에 개인용 업무 화면을 엽니다. 첫 버전은 오늘·내일 부서원 비근무 현황을 실제 연동하고, 나머지 카드는 준비 화면으로 제공합니다.

## 바로 사용할 파일

- `dist/install.html`: 브라우저에서 열어 보는 등록 안내와 실행 코드 복사 버튼.
- `dist/nextep-bookmarklet.txt`: 즐겨찾기의 URL 칸에 넣을 최종 실행 코드. 한 줄 전체를 복사합니다.
- `dist/nextep-favorites.html`: 브라우저의 즐겨찾기 가져오기에 사용할 파일.
- `dist/demo.html`: 인터넷 연결과 설치 없이 열 수 있는 가상 데이터 미리보기. 실제 EP 조회를 하지 않습니다.
- `dist/probe-url.txt`: 새 탭·기존 로그인·조회 응답만 확인하는 짧은 연결 확인 코드.

`dist` 폴더의 파일은 Node.js 설치 없이 사용합니다. 외부 웹 호스팅이나 외부 라이브러리 연결이 없습니다.

## VDI에서 등록

1. VDI의 Edge에서 EP를 통해 NEXTEP에 로그인합니다. 주소가 `https://portal.posco.net/`으로 시작하는 탭을 사용합니다.
2. 최종 실행 코드 파일 전체를 복사합니다.
3. NEXTEP 탭에서 **Ctrl+D → 더 보기**를 누릅니다.
4. 이름을 **개인 NEXTEP**로 지정합니다.
5. **URL 칸 클릭 → Ctrl+A → Backspace → 붙여넣기** 순서로 기존 주소를 교체합니다. 시작이 `javascript:`인지 확인하고 **저장**합니다.
6. NEXTEP 탭에서 **Ctrl+Shift+O**로 즐겨찾기 목록을 열고 **개인 NEXTEP**를 클릭합니다.

이번 VDI 검증에서는 실행용 즐겨찾기를 **My NEXTEP**라는 이름으로 구분해 두었습니다.

코드는 브라우저 **주소창이나 검색창에 붙여넣지 않습니다**. 기존 URL 뒤에 붙이지 않습니다. 원격 환경에서 자동 텍스트 입력이 전달되지 않을 수 있으므로 직접 복사·붙여넣기로 등록합니다. 파일 전송이 가능한 환경에서는 `nextep-favorites.html`을 VDI로 가져와 Edge의 즐겨찾기 가져오기를 이용할 수도 있습니다.

## 사용

- 오늘·내일은 한국 시간 기준입니다. 선택한 날짜의 이름·직급·원본 비근무 유형을 표시합니다.
- 인원은 원본 식별자 기준 중복 제거, 유형별 건수는 표시된 비근무 기록 기준입니다. 한 사람에게 여러 유형이 있으면 유형 합계와 인원수가 다를 수 있습니다.
- 이름 검색과 유형 필터를 함께 사용할 수 있습니다. 날짜를 바꾸면 유형 필터를 초기화하고 이름 검색은 유지합니다.
- 열 때 조회하고, 보고 있는 동안 5분마다 자동 갱신합니다. 숨긴 탭에서는 주기 조회를 멈추고, 돌아왔을 때 결과가 5분 이상 지났으면 즉시 조회합니다. 자정에도 날짜를 재확인합니다.
- 수동 새로고침과 즐겨찾기 재실행으로 갱신할 수 있습니다. 재실행은 열려 있는 개인 NEXTEP 탭을 재사용합니다.
- 로그인 만료·권한 오류가 나면 자동 갱신을 중지합니다. EP에서 직접 로그인한 뒤 **로그인 후 재시도**를 누릅니다.
- 연결 실패 시 이전 목록과 마지막 성공 시각을 유지하고 이전 결과임을 알립니다. 실패를 빈 목록으로 표시하지 않습니다.
- 개인 NEXTEP의 `about:blank` 탭을 브라우저에서 새로고침하거나 종료하면 화면이 사라집니다. NEXTEP 원본 탭에서 즐겨찾기를 다시 누르면 됩니다. 세션 복원 시에도 같은 방식으로 엽니다.

원본에 기간이 없어 첫 버전에는 기간을 표시하지 않습니다. 임의 날짜 조회·근무 가능 인원 계산·메일·일정·To-Do 연동은 포함하지 않습니다.

## 사내 PC로 이전

1. `dist` 폴더와 이 안내를 회사에서 사용하는 전달 방법으로 사내 PC에 옮깁니다.
2. 사내 PC의 브라우저에서 EP/NEXTEP 로그인과 비근무 조회 권한을 확인합니다.
3. VDI와 동일한 방식으로 즐겨찾기를 등록합니다. 별도 프로그램·확장 설치는 필요하지 않습니다.
4. 원본 내일 카드와 개인 NEXTEP의 이름·직급·유형을 대조하고, 수동 새로고침 후 마지막 성공 시각이 바뀌는지 확인합니다.
5. 화면을 켜둔 채 5분 후 시각이 갱신되는지 확인합니다. 브라우저 정책이 다르면 VDI에서의 성공과 별도로 실행 가능 여부를 확인해야 합니다.

## 데이터 처리

실제 조회는 `GET https://portal.posco.net/api/attend/briefing` 한 곳을 사용합니다. 브라우저의 기존 동일 사이트 로그인 상태로 요청합니다. 쿠키·토큰을 읽거나 복사하지 않으며, 별도 로그인 정보를 받지 않습니다.

응답의 `today`, `tomorrow` 배열에서 `lid`는 인원 식별, `nm`은 이름, `jt`는 직급, **`offName`은 비근무 유형**으로 읽습니다. `offName`의 대소문자를 그대로 사용합니다.

실제 명단과 응답은 화면·메모리에서만 사용합니다. localStorage, sessionStorage, 파일, 서버 로그로 저장하지 않습니다. 브라우저의 즐겨찾기에는 실행 코드만 들어갑니다. 페이지를 닫으면 목록을 유지하지 않습니다. 가상 데이터 테스트와 미리보기에는 합성 인물만 사용합니다.

브라우저의 새 탭 차단·사이트 정책·회사 네트워크 통제를 해제하지 않습니다. 실행이 차단되면 안내를 표시하고 실제 연동 성공으로 처리하지 않습니다.

## 개발 및 검증

Node.js 24 환경에서 외부 패키지 설치 없이 실행합니다.

```text
node scripts/build.mjs
node --test
node scripts/serve.mjs
```

미리보기 주소는 `http://127.0.0.1:4173/`입니다. 실행용 결과물은 `dist`에 생성됩니다. 소스를 고쳤으면 다시 빌드하고, 기존 개인 NEXTEP 탭을 닫은 뒤 갱신된 즐겨찾기로 실행합니다.

- `src/core.mjs`: 응답 정규화, 날짜, 집계·필터, `loadAbsences()` 로더 생성, 갱신·오류 제어.
- `src/ui.mjs`, `src/style.css`: 화면과 접근성·반응형 배치.
- `src/launcher.mjs`: 실행 사이트 확인과 새 탭 생성·재사용.
- `src/demo.mjs`: 외부 데이터가 없는 미리보기와 오류 상태 선택.
- `test`: 정규화·인증·시간초과·자정·갱신·응답 역전·새 탭 재사용과 결과물 검사.

원본 API는 사내 비공개 인터페이스이므로 원본 변경 시 연동 수정이 필요할 수 있습니다. 검증 범위와 남은 확인 사항은 `VERIFICATION.md`에 기록합니다.
